Exercise 4 - A: Configuration of IP Address in Router
Objective: Connect 2 PCs directly to a Router using Copper cross-over cables → configure /24 IPs and default gateways → enable Router interfaces via CLI → verify connectivity.

STAGE 1 Physical Topology Construction (Part A)

Drag 2 PCs (PC0, PC1) and 1 Router (Router0) onto the canvas.
Connect PC0 → Router0 and PC1 → Router0 using Copper cross-over cables.

Exercise 4 - B: Subnetting in WAN Configuration (DTE and DCE)
Objective: Build a WAN topology using 4 PCs and 2 Routers → apply /27 VLSM subnetting → install HWIC-2T serial modules → configure static routing → verify end-to-end routing.

STAGE 1 Step 1: WAN Topology Construction (4 PCs & 2 Routers)

Drag 4 PCs (PC0, PC1, PC2, PC3) and 2 Routers (Router0, Router1) onto the canvas.
Connect PC0 & PC1 → Router0 with Crossover cables, Router0 ↔ Router1 with Serial DCE cable, and PC2 & PC3 → Router1 with Crossover cables.

Router

STAGE 2 Steps 2–5: Router Physical Hardware Configuration (HWIC-2T Serial Module)

In Cisco 1941 Routers, serial ports are added via the HWIC-2T module. The hardware power switch must be turned OFF before inserting the module, then switched back ON.

Router0 Hardware View POWER ON
Slot 0: Empty (Serial0/1/0 unavailable)
Router1 Hardware View POWER ON
Slot 0: Empty (Serial0/1/0 unavailable)
