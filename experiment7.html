Build the WAN topology → configure IP addresses → enable RIP v1 on Router0 & Router1 → observe dynamic route learning → verify connectivity.

Drag 4 PCs (PC0…PC3), 4 Switches (Switch0…Switch3), and 2 Routers (Router0, Router1) onto the canvas.
Connect: PCs → Switches (Straight-Through), Switches → Routers (Straight-Through), Router0 ↔ Router1 (Serial DCE).

Exercise 7.B — RIP v2: Classless Routing with /27 Subnetting
Build the same topology using /27 subnetted addresses → configure RIP v2 with no auto-summary → verify /27 routes appear with exact subnet masks.

STAGE 1 Topology Status

Part B uses the same physical topology as Part A (4 PCs, 4 Switches, 2 Routers). Complete Part A topology validation first — Part B will use it automatically.

✔ Topology validated from Part A. Proceed to RIP v2 configuration below.

STAGE 4 Live Dynamic Routing Tables — /27 Subnets

After convergence, note that R routes show exact /27 subnet masks — proof that RIP v2 carries subnet-mask information in its updates.

STAGE 5 RIP v2 Subnet-Aware Packet Routing Simulation

The router performs a longest-prefix match against /27 subnet entries to decide forwarding. Observe the subnet lookup at each hop.

→
