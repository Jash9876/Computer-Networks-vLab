STAGE 3 Cisco IOS CLI — HDLC Framing & Hardware Inspection

Step-by-Step CLI Instructions:
1. Inspect Hardware: show controllers serial0/1/0 (verifies DCE/DTE clocking).
2. Configure Serial IP & HDLC: int se0/1/0 → ip address 192.168.1.1 255.255.255.0 → encapsulation hdlc → no sh.
3. Verify Status: show int se0/1/0 (confirms Encapsulation HDLC).
